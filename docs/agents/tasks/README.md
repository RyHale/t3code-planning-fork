# Agent Board Task Records

This folder holds durable task records for the T3 Code authoritative agent
board.

Every non-trivial task record should include:

- owner intent
- target status
- scope guard
- acceptance criteria
- verification
- parallelism plan
- proof-of-done notes before `Status: done`

The visual board is the operational control surface. The task record preserves
intent, proof, and decisions.
