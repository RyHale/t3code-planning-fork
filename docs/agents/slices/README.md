# Agent Board Slice Plans

Slice plans describe branches of related work for the T3 Code authoritative
agent board. They provide direction and guardrails for multiple task records.

Read order for agents:

1. `WORKFLOW.md`
2. `PROJECT.md`
3. `CONTEXT.md`
4. `docs/agents/project-master-plan.md`
5. the relevant slice plan in this folder
6. the linked task record under `docs/agents/tasks/`

The slice plan explains direction. The task record controls the exact runnable
scope.
